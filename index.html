Welcome to the Dispatch Yard

This page is the neighbourhood yard where residents share tools with each other, styled as a shipping dispatch dock. Browse what's on the shelf, request an item, catch the community announcement, join the yard, vote in the neighbourhood poll, and check your dashboard — all built with native HTML5 Drag and Drop, Web Storage, and hands-on JavaScript event handling.

Need a hand

Help

Crate won't drag?

Make sure you click and hold directly on a crate, then move the mouse before releasing over the pallet.

What's the difference between the lockers?

The Long-Term Locker (localStorage) keeps data after you close the browser. The Temporary Crate (sessionStorage) empties out once the tab is closed.

How do I remove saved data?

Use the "Clear Stored Data" button in the Filing Office section to wipe both lockers at once.

How the Interactions Work

Where's the event delegation?

The Discussion section attaches one listener to the comments list, so newly created Reply buttons and comments work without extra listeners.

How does the poll timer work?

Starting the poll begins a setInterval() countdown. When it hits zero the poll auto-submits and locks.
